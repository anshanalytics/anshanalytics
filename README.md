# 🏠 Gurgaon Real Estate Market Analysis

## 📌 Overview
This project analyzes the Gurgaon real estate market using **Exploratory Data Analysis (EDA)** to understand patterns, relationships, and anomalies in property data before applying any advanced modeling.

## 🎯 Approach
The solution is divided into logical steps:
1. **Data Loading and Understanding** – Importing the dataset and exploring its structure
2. **Data Cleaning and Preparation** – Handling missing values, duplicates, and inconsistencies
3. **Analysis** – Answering key business questions through visualization and statistics
4. **Summary of Insights** – Consolidating findings into actionable conclusions

## 🔧 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn

## 📂 Files
- `main.py` - Main EDA and analysis script
- `data.csv` - Gurgaon real estate dataset
